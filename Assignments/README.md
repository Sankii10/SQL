# SQL Assignments

## Overview

This directory contains SQL assignments completed as part of academic coursework and structured SQL learning programs.

The assignments focus on developing a strong foundation in relational database concepts, query writing, data retrieval, data manipulation, and analytical problem-solving using SQL.

These exercises helped strengthen practical database skills and provided hands-on experience with real-world querying scenarios.
