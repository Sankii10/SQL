# CoachX SQL Assignments

## Overview

This directory contains SQL assignments completed through the CoachX learning program.

The assignments are designed to strengthen practical SQL skills through hands-on exercises involving database querying, data analysis, and problem-solving using relational databases.

These exercises focus on applying SQL concepts in realistic scenarios and improving query-writing efficiency.
